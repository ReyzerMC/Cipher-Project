# ⚔️ Cipher Calculator

**Cipher Project**

Una pagina donde se podran consultar datos de los personajes para **Honkai: Star Rail**.

> [!NOTE]
>
> El projecto acutalmente se encuentra en **su primera release** puede que haya fallos, se pide que los reporten en caso de encontrarlos

---

## 🌐 Página oficial

Puedes acceder a la pagina mediante este enlace:

**https://cipher-calculator.reyzer.org/**

---

## 📊 Estado actual

El proyecto se encuentra en su primera release.

### Personajes

Actualmente estan **todos los personages hasta la version 4.5**.

### Conos de Luz

Actualmente estan **todos los Conos de Luz implementados hasta la version 4.5**.

---

## 💻 Compatibilidad

### 🖥️ Ordenadores

La interfaz está actualmente diseñada y ajustada principalmente para:

* **1920×1080 (1080p)**
* **2560×1440 (2K)**

La experiencia puede variar en otras resoluciones o relaciones de aspecto.

### 📱 Móviles y tablets

> [!NOTE]
> La compatibilidad con móviles y tablets **recien implementada, si experimentan algun tipo de falla crear una issue en github**.

---

## 🛠️ Tecnologías

El proyecto está desarrollado utilizando:

* **React**
* **TypeScript**
* **Vite**
* **ESLint**

La aplicación utiliza React + TypeScript como base para la interfaz y Vite como herramienta de desarrollo y compilación.

---

## 🎨 Diseño

La estructura y parte de la organización visual de la página están **parcialmente basadas en la estructura de**:

## 🐛 Reportar errores

Si encuentras:

* Errores de interfaz
* Cálculos incorrectos
* Personajes que no funcionan correctamente
* Conos de Luz que no aparecen
* Problemas de compatibilidad
* Problemas visuales
* Crashes
* Cualquier otro comportamiento inesperado

por favor, **abre un Issue en este repositorio**.

### Antes de abrir un Issue

Si es posible, incluye:

1. Una descripción clara del problema.
2. Los pasos necesarios para reproducirlo.
3. El navegador utilizado.
4. La resolución de pantalla.
5. Capturas de pantalla si ayudan a explicar el problema.
6. Cualquier mensaje de error que aparezca en la consola.

Esto ayudará considerablemente a localizar y solucionar el problema.
