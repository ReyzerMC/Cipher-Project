# ⚔️ Cipher Project

**Honkai: Star Rail — Damage Calculator**

A page where you can find data about all the **Honkai: Star Rail** characters.

> [!NOTE]
>
> This project is in its 1st Release it might have errors.

---

## 🌐 Official Website

You can use the page here:

**https://cipher-calculator.reyzer.org/**

---

## 📊 Current Status

The project is in its 1st Release

### Characters

There are currently **all characters available up to 4.5 version**.

### Light Cones

There are **all the Light Cones implemented up to 4.5 version**.

---

## 💻 Compatibility

### 🖥️ Desktop

The interface is currently designed and primarily optimized for:

* **1920×1080 (1080p)**
* **2560×1440 (2K)**

The experience may vary on other resolutions or aspect ratios.

### 📱 Mobile & Tablets

> [!NOTE]
> Mobile and tablet compatibility **has just been added, if errors are found, please create an github issue**.

---

## 🛠️ Technologies

This project is built using:

* **React**
* **TypeScript**
* **Vite**
* **ESLint**

The application uses React + TypeScript as its main frontend stack, with Vite being used as the development and build tool.

## 🐛 Reporting Issues

If you encounter:

* Interface bugs
* Incorrect calculations
* Characters not working correctly
* Missing Light Cones
* Compatibility issues
* Visual problems
* Crashes
* Any other unexpected behavior

please **open an Issue in this repository**.

### Before Opening an Issue

If possible, please include:

1. A clear description of the problem.
2. The steps required to reproduce it.
3. The browser you are using.
4. Your screen resolution.
5. Screenshots if they help explain the problem.
6. Any error messages shown in the browser console.

This will make it considerably easier to identify and fix the problem.
